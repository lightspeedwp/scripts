# Deployment Scripts

This directory contains scripts related to deployment and release processes.

## Scripts

| Script                                                 | Description                                                                                                           |
| ------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------- |
| [`example-deployment.sh`](./example-deployment.sh)     | An example template for a deployment script, demonstrating a basic structure for deploying to different environments. |
| [`run-deployment-tests.sh`](./run-deployment-tests.sh) | A convenience script for running the Bats tests specific to the deployment scripts.                                   |

## Documentation

Each script has a corresponding `README.<script-name>.md` file that provides detailed information about its purpose, usage, and technical implementation.

- [`README.example-deployment.md`](./README.example-deployment.md)

For detailed usage and technical information, please refer to the individual `README` files.
